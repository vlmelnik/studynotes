## Download

- **StudyNotes-Setup-….exe** – installer for Windows 10 / 11 (recommended). Updating: just install over the old version.
- **StudyNotes-…-win-x64.zip** – portable version: unzip anywhere, start `StudyNotes.exe`.

Windows SmartScreen may show *"Windows protected your PC"* because the app is not code-signed: **More info → Run anyway**.
